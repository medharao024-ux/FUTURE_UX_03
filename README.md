# ✦ NOVA CRM
### `Agency Client Management Dashboard`

> **One workspace. Every client. Every opportunity. Every follow-up.**

NOVA CRM is a modern **B2B CRM dashboard** designed for agencies and service-based teams to manage their complete client workflow — from **lead discovery → sales pipeline → client management → project tracking → follow-ups**.
